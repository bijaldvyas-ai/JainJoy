JainJoy 2.0 - Jain Meal Planner
===============================

Live app:  https://bijaldvyas-ai.github.io/JainJoy/
Tests:     open tests/index.html on any web server

What is inside
- 391 Jain recipes (English, Hindi, Gujarati), regional thali planner
- Jain Panchang for your city: tithi, Shukla Pancham, Aatham, Chaudas, festivals
- Navkarsi and Chauvihar timings, monthly calendar with history, grocery lists
- Recipe admin, food glossary, all 36 Indian states and UTs

Run on this computer:  double-click START-JainJoy.bat  (http://localhost:8080)

Documents
- docs/PRD-v2.0.md       product requirements
- docs/TEST-REPORT.md    test results
- docs/SETUP.md          setup, publishing, dependencies
- db/schema.sql          server database schema; db/migrations/

Your data stays on your phone. It is not uploaded anywhere.
